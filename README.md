# OXXO Landing Page

Responsive static website created as a university exercise in HTML and CSS. It presents a convenience-store brand, its mission, services and social links.

## Technologies

HTML5, CSS3, CSS Grid and responsive media queries. No JavaScript, backend or build tools.

## Features

- Company presentation and three illustrated service cards.
- One, two or three columns depending on viewport width.
- Image alternative text and links to social profiles.

## Run locally

```bash
git clone https://github.com/Angel0208ia/oxxo-landing-page.git
cd oxxo-landing-page
```

Open `index.html` in a browser. Alternatively, with Python installed, run `python -m http.server 8000 --bind 127.0.0.1` and visit http://localhost:8000.

## Project structure

`index.html` contains the page; `style.css` contains the layout; `1.webp`, `2.webp` and `3.jpg` are content images, not application screenshots.

## Scope and verification

Beginner academic project demonstrating semantic markup, styling and responsive layout. Check the page at phone, tablet and desktop widths. This is an unofficial educational exercise, not an official OXXO website. Brand names and images belong to their respective owners.
